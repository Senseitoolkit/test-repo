How to run a walkaround
  1. Print the question posters (A4 landscape, one question per page) and put them up around the room.
  2. Print a working-out paper for each student. It has numbered lines for every question.
  3. Students walk the room and write their working and answer next to each question number.
  4. Go through it together with Present on board and reveal each answer, or mark with the answer key. Set B practises the same skills with new numbers.
