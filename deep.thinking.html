Visible Thinking Routines

Short, memorable structures that students use again and again until the thinking moves become habits. Filter by purpose or domain, then open a routine for its steps, best uses and a ready-to-use classroom example.

Making routines work

  • Repeat them. Use a small set often rather than many once. The routine should become the class's own language.
  • Pick by purpose. Choose the routine for the thinking you want (noticing, connecting, reasoning), not for novelty.
  • Document it. Record responses on charts, sticky notes or slides so thinking stays visible and can be revisited.
  • Press for reasons. Follow up any claim with "What makes you say that?"
  • Hand it over. Over time, let students choose which routine fits the task.
  • Reskin it. Reuse a routine's structure for a new purpose or subject so it stays familiar without going stale.
  • Vary the mode. Mix talking, writing, drawing and building on purpose, so no routine becomes only a talking routine.
  • Name the subskills. A routine assumes skills of its own (turn-taking, giving reasons, reading a chart) — teach these if they're missing.
  • Build stamina early. Start with short, well-supported rounds before expecting full independence and self-direction.
  • Use visual schedules. Post the steps where students can see them until the routine is internalised.

Assessment that asks "what next?"

  • Writing baseline sets goals, groups and scaffolds.
  • Reading level check informs grouping and ongoing feedback.
  • Maths pre/post tests show starting points and remaining gaps.
  • Exit tickets check application, not just recall.
  • Conference notes capture individual strategies and needs.

Classroom displays

Displays do quiet work: they hold strategies, goals and thinking where students can return to them, so nothing depends on memory or on asking the teacher. Rebuild each in the same place, the same way, every unit — the familiar structure is what lowers the cognitive load.

Display wall

The reference wall for strategies and quality.

  • Writing-process and traits-of-writing examples tied to the current unit
  • Anchor charts for each step of the reading checklist
  • Essential strategies and concepts for each strand
  • A thinking-routine question-depth display, built with student examples

Inquiry wall

Co-built with students; rebuilt the same way each unit so the structure itself becomes familiar.

  • A See-Think-Wonder provocation, with student input added as it grows
  • The unit's central idea, unpacked into plain language
  • Each inquiry question broken into the concepts, skills and ideas it involves
  • A worked example showing how the final task blends them together

Whiteboard

The daily operating surface — goals, vocabulary and lesson flow.

  • This week's goals and the baseline tasks to return to in downtime
  • Lesson slides built with clear cues for pair-share, mini-whiteboards, signals, rehearsal or timed independent work
  • A slide sequence that scaffolds toward centers or stations
  • Key or challenging vocabulary for the lesson, and a steps sign for the task at hand
