How It Works

The same three steps for English and maths

1

Choose a grade and form

Every grade has 11 forms (A–K). Each form has the same question types with new texts, numbers and pictures, so you can compare results from one test to the next.

2

Run it on screen or on paper

Use a Tester for pupils on devices, or print the paper from Mock Papers. With the same set number, both give the same test.

3

Mark and record

The Testers mark answers and show a skills report as soon as pupils finish. For paper, use the answer key with the matching paper code, then fill in the score sheet.
